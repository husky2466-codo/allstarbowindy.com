# All Star Bowl — BAC Membership Card Art Prompts (for ElevenLabs / nano-banana-pro)

## Concept: "The All-Star Graffiti Wall" — one mural world, a different graffiti style per tier
Every card is a fresh piece sprayed on the **same deep-navy wooden-plank wall**, with the patriotic **crossed-pins shield crest**, a multicolor **spray-dot halo**, and scattered **red & cyan stars** — so all five read as one family. What changes per tier is the **graffiti style of the "ALL STAR BOWL" wordmark**, escalating from a quick throw-up to a full wildstyle burner. "Chrome," "gold-leaf," and "wildstyle burner" are authentic graffiti techniques, so the Silver/Gold/Diamond names stay on-brand and stay FUN.

## How to use
1. **Attach two references** in ElevenLabs: `assets/logo.png` (the shield) and `card-reference.html` screenshot (for layout/composition + the navy graffiti-wall look).
2. Say: *"Match the layout and navy graffiti-wall style of the reference card; keep the crossed-pins-and-ball shield faithful to the logo."*
3. **Aspect ratio:** a true credit-card is 1.586:1, which the generators don't list — so pick the closest: **16:9** (recommended), or **3:2** if your model offers it (even closer). Avoid 4:3 / 5:4 (too square). Keep the crest + wordmark centered with margin, then optionally crop the sides down to ~1.586:1. Rounded corners.
4. **Keep the lower-left third calm** — the website overlays member name / ID / games there.
5. Generate **BAC first**, then feed that result back as a style reference for the other four so composition stays identical and only the wordmark's graffiti style changes.

## Tips for a clean, consistent set
- Lock **BAC's** composition first, then use it as the style reference for the rest — only the wordmark technique + accent changes.
- If lettering comes out misspelled, simplify the wordmark or let the website render the text and ask the AI for the wall + crest + halo only.
- Request a **solid-navy or transparent background** so the card drops onto the page cleanly.
- Keep the spray-dot halo and red/cyan stars on EVERY tier — that's the glue that makes them a set.
