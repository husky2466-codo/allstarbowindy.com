# LiveScores / Computer Score Login — Live-Site Reference

**Saved:** 2026-06-07
**What this is:** A saved copy of the current All Star Bowl website's league
**LiveScores** system — specifically the **Computer Score login** page where
bowlers/leagues sign in to view live computer-scored results. Captured as
designer reference for the allstarbowindy.com rebuild.

This is reference material only (not a deployed page). Top-level filenames that
contained spaces were sanitized (spaces -> hyphens). Internal asset filenames
were left intact so relative links inside the saved HTML still resolve where
possible. Link rewriting was intentionally not done.

## Key files

- `all-star-bowl-livescores-login.html` — the saved LiveScores login page
  (originally "All Star Bowl - LiveScores Login.html").
- `computer-score.html` — the Computer Score page (originally "Computer Score.html").
- `computer-score_files/` — nested asset folder for the Computer Score page
  (originally "Computer Score_files"): `background.css`, `leagues.css`,
  `login-bowler.css`, `computer-score.png`.
- CSS: `background.css`, `login-bowler.css`, `master.css`, `view-lanes.css`.
- JS: `expand.js` (page behavior), `jquery-latest.min.js` (generic jQuery
  library — copied to keep the page self-contained; not project code).
